# プライバシーポリシー（原案）

最終更新日: 2026年10月28日
アプリ名: もぐログ（MoguLog）

> これは App Store 公開用の原案です。公開前に運営者名・連絡先を記入し、内容をご確認ください。

## 1. 取得する情報

本アプリは、利用者がアプリ内で入力・撮影した以下の情報を、**利用者の端末内にのみ**保存します。

- 食事の記録（食品名、量、栄養素の推定値、食事の写真）
- 体重の記録
- プロフィール情報（年齢、性別区分、身長、体重、目標、活動レベル）

アカウント登録は不要であり、氏名・メールアドレス・位置情報は取得しません。

## 2. 情報の送信・第三者提供

- 本アプリは、上記の情報を外部サーバーへ送信しません。解析・集計はすべて端末内で処理します。
- 広告SDK、解析（トラッキング）SDK、課金SDKは組み込んでいません。
- 個人データを第三者へ販売・提供することはありません。

## 3. 端末の権限

- カメラ: 食事の写真を撮影するためにのみ使用します。
- 写真ライブラリ: 利用者が選択した食事の写真を取り込むためにのみ使用します。
- 取り込んだ写真はアプリの端末内領域にコピーされ、外部へ送信されません。

## 4. データの管理と削除

- データは端末内のデータベース（SQLite）とファイル領域に保存されます。
- アプリ内の「設定 → すべての記録を削除」から、すべての記録をいつでも完全に削除できます。
- CSVエクスポートおよびJSONバックアップは、利用者自身の操作で共有シートを通じて書き出されるもので、開発者が受け取ることはありません。

## 5. 栄養情報についての注記

表示される栄養素の値は、日本食品標準成分表（文部科学省）の代表値に基づく推定値であり、医療・診断目的のものではありません。健康状態に関する判断は医療専門家にご相談ください。
