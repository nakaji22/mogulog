# App Store 公開手順書

## アプリ基本情報（提出用ドラフト）

- **アプリ名候補**: もぐログ（第一候補） / もぐログ – 無料の食事記録 / MoguLog
  ※ App Store Connect で名前の空きを確認すること。同名アプリがある場合はサブタイトルで差別化する
- **Bundle Identifier**: `com.mogulog.app`（app.json と一致。独自ドメインを持っている場合は `app.<ドメイン>` 形式への変更を推奨。その際 app.json・ExportOptions.plist・Developer ポータルの App ID をすべて揃える）
- **カテゴリ**: ヘルスケア/フィットネス（主）、ライフスタイル（副）
- **価格**: 無料（アプリ内課金なし）

### App Store 説明文（原案）

```
もぐログは、写真で記録する完全無料の食事管理アプリです。
広告なし、サブスクリプションなし、アプリ内課金なし。ずっと無料で使えます。

■ 写真でかんたん記録
食事を撮影すると、よくある料理の候補と標準的な一人前の栄養目安を提示します。
量はグラムと「何人分」で細かく調整でき、合計カロリーとPFC（タンパク質・脂質・炭水化物）がその場で再計算されます。

■ 栄養データ
日本食品標準成分表（文部科学省）の代表値をもとにした食品データベースを内蔵。
ご飯や唐揚げなどの定番メニューから、野菜・果物・飲み物まで幅広く記録できます。

■ 目標と分析
年齢・身長・体重・活動レベルから推奨摂取カロリーを自動計算（極端な制限は推奨しない安全設計）。
7日・30日のカロリー推移、PFCバランス、体重の変化、連続記録日数をグラフで確認できます。

■ プライバシー
記録はすべてあなたの端末内に保存されます。アカウント登録不要、外部送信なし、トラッキングなし。
CSVエクスポートとJSONバックアップ（復元可能）にも対応しています。

※ 表示されるカロリー・栄養素は推定値です。
※ 写真から料理を自動判定するAI機能は搭載していません。候補提示と手動補正による記録方式です。
```

- **サポートURL**: （公開前にサポートページのURLを用意。GitHubリポジトリの公開ページ等でも可）
- **プライバシーポリシーURL**: docs/PRIVACY_POLICY.md を公開ページに掲載したURL

### 権限の説明文（Info.plist設定済み）

- カメラ: 「食事の写真を撮影して記録するためにカメラを使用します。写真は端末内にのみ保存されます。」
- 写真: 「食事の写真を選んで記録するために写真ライブラリへアクセスします。写真は端末内にのみ保存されます。」

### スクリーンショットの準備方法

1. TestFlight版を実機に入れ、サンプル記録を数件入れる（実在の個人情報は入れない）
2. ホーム / カメラ（候補選択）/ 記録カレンダー / 分析 の4〜6画面を撮影する
3. 必要サイズ: 6.9インチ（1320×2868）等、App Store Connect の現在の要求に従う
4. Macが無い場合は実機のスクリーンショット機能で撮影すればよい（Xcode不要）

## 公開までの手順

前提: Apple Developer Program への登録（年額・本人確認・支払い）は**開発者本人が**行うこと。ここではその後の手順を示す。

1. **App Store Connect でアプリを作成**
   - マイApp → 新規App → プラットフォーム iOS、名前「もぐログ」、主要言語 日本語、Bundle ID `com.mogulog.app`、SKU `mogulog-ios-001`
2. **署名とAPIキーの用意** → docs/BUILD_IOS.md の手順で GitHub Secrets を登録
3. **署名付きビルドをアップロード**
   - GitHub Actions「iOS Build」を build_mode=archive / upload=有効 で実行
   - App Store Connect の TestFlight タブにビルドが表示されるまで待つ（処理に時間がかかる場合がある）
4. **TestFlightで実機確認**
   - TestFlightアプリで自分のiPhoneにインストールし、主要フロー（オンボーディング→写真記録→編集→分析→エクスポート）を確認
   - 内部テスターは審査なしで配信可能。外部テスターはベータ版審査が必要
5. **ストア掲載情報を入力**
   - 上記の説明文・キーワード・スクリーンショット・プライバシーポリシーURL・サポートURL
   - Appのプライバシー（プライバシー選択肢）: 「データが収集されません」に相当する申告（本アプリはデータを外部送信しない）
   - 年齢制限レーティング: 質問票に回答（該当コンテンツなし）
   - 輸出コンプライアンス: app.json で `ITSAppUsesNonExemptEncryption=false` を設定済み
6. **審査へ提出**
   - バージョン画面でビルドを選択し「審査へ提出」
   - 審査ノートには「完全無料・課金なし」「写真の候補提示方式であり自動判定AIではない」「アカウント不要で全機能が使える」旨を明記すると審査がスムーズ
7. **公開**
   - 承認後、手動リリースまたは自動リリースを選択して公開

## 審査で想定されるポイント

- 健康関連の主張をしない（「痩せる」等の効能表現を説明文に使わない）
- 栄養値が推定であることをアプリ内・説明文の両方で明示（実装済み）
- 権限ダイアログの文言と実際の用途の一致（設定済み）
- クラッシュなく主要フローが動作すること（TestFlightで事前確認）
